# Журнал изменений

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии — по [SemVer](https://semver.org/lang/ru/): модель и CLI обратно совместимы внутри мажорной версии.

## [0.2.1] — 2026-11-15

Иконка окна, поставка и проверки, которых не хватало.

### Добавлено
- **`window-icon "icon.png"`** — иконка окна своим PNG-декодером (`src/png.rs`): zlib с полным inflate
  (stored, fixed, dynamic Huffman), пять фильтров строк, цветовые типы 0/2/3/4/6, глубина 8 и 16 бит.
  На сборке картинка уменьшается до 48×48 и вшивается пикселями в `egui::IconData`; декодер в приложение
  не попадает.
- **`lazr png FILE [--raw OUT]`** — тот же декодер наружу, для сверки с другими инструментами.
- **`lazr package` сам генерирует проект**, а в архив кладёт модель (`form.lazr`), `LICENSE` и `VERSION`;
  в `.desktop` появились `Version=1.0`, версия lazr в `Comment` и `X-Lazr-Model`.
- Метаданные `Cargo.toml` для публикации: `repository`, `homepage`, `readme`, `keywords`, `categories`.
- CI: сборка и `verify` каждой модели, `fmt --check`, шаг с иконкой из настоящего PNG.
- Тег `v0.2.0` и GitHub Release.

### Исправлено
- **`transparent:yes` теперь действительно прозрачен**: фон окна не закрашивается, иначе прозрачность
  не была бы видна.
- **`lazr package` падал на «cargo не запустился»**, если проект ещё не собирали: рабочего каталога не было.
- **PNG: двойное разворачивание кодов Хаффмана** — канонические коды не нужно реверсировать, иначе ломались
  все настоящие PNG. Поймано сверкой с ImageMagick.

### Проверено
- PNG-декодер: побайтовое совпадение с `convert FILE rgba:-` для RGBA, RGB, палитры и градаций серого.
- Иконка в окне: `xprop -id <окно> _NET_WM_ICON` печатает `Icon (48 x 48)`.
- `resizable:yes` → окно меняет размер (400x300 → 620x420), `resizable:no` → не меняет.
- Тултип `{hint:"…"}` виден на скриншоте при наведении.
- Тултипы и подписи `/` прозрачность: прозрачность подтверждена только кодом (`with_transparent(true)`),
  потому что снимок окна отдаёт его собственный буфер, а не композит рабочего стола.

## [0.2.0] — 2026-11-15

Первый срез, который можно ставить людям, а не только показывать.

### Добавлено
- **Хранилище состояния**: `store "путь"` — значения полей читаются при старте и пишутся при изменении.
  Запись атомарная (временный файл + `rename`), `~` раскрывается в `HOME`, списки пишутся через `\u{1f}`.
- **Своя рамка окна**: `chrome:own` (заголовок и крестик рисует приложение, двойной клик — развернуть),
  плюс `resizable`, `topmost`, `transparent`, `drag-anywhere`, `min`, `max`, `center`.
- **Свой шрифт текста** `font-family "путь.ttf"`, **моноширинный текст** `{mono}`, **подсказки** `{hint:"…"}`.
- **`lazr fmt FILE|DIR [--check]`** — канонический вид модели; проверено, что форматирование идемпотентно.
- **Скилл стилей**: 42 стиля (`skills/design-styles/SKILL.md`) готовыми строками `theme`.
- Демки: `player.lisp` (плеер с визуализатором), `cinema.lisp`, `terminal.lisp` (моно + своя рамка),
  `todo.lisp` теперь помнит себя между запусками.
- CI: сборка и `verify` **каждой** модели `.lazr`, `fmt --check`, шаги на хранилище, шрифт и свою рамку.

### Исправлено
- **Фон окна не рисовался**: `eframe 0.37` отдаёт голый `Ui`, поэтому светлая тема выглядела чёрной.
  Теперь панель красится цветом темы до отрисовки виджетов.
- **`fmt` сдвигал блоки `rust`** на 4 пробела за прогон — блоки хранятся и пишутся дословно.
- **Модель со своими `rust`-полями не собиралась**: `State` больше не требует `Debug/Clone/PartialEq`
  от пользовательских типов, хранилище сравнивает только поля модели (`ModelFields`).
- **Токенизатор рвал стиль на кавычках** (`{hint:"два слова"}`) — кавычки внутри `{…}` теперь часть токена.
- **`is_style_token`** распознаёт стиль по известным ключам, а не по наличию `:`.
- **Рантайм отставал от модели** (`font-family` в S-выражениях) — добавлен и закрыт тестом по `RUNTIME_SRC`.
- Тема принимает строку стиля как есть (`accent:#00a2e8`), числа читаются и из строки.
- `text_input` больше не сливается с фоном тёмной темы.

## [0.1.0] — 2026-11-14

- Модель экрана, генератор egui/eframe, два синтаксиса (строчные формы и S-выражения).
- Поля, списки, `when`/`else`, `place`, карточки, иконки из внешнего TTF.
- `lazr live` исполняет формы напрямую, `verify` печатает диф полей, `package` собирает `dist/`.
