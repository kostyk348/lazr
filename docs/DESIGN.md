# Токены дизайна lazr

Направление: **тёмный инструментальный** (вариант 1). Одна тема на все демо — расхождение токенов считается
дефектом, как и расхождение поведения.

## Отступы (шкала 4)

| Токен | Значение | Где |
|---|---|---|
| `pad` контейнера | 10 | внешняя рамка экрана |
| `spacing` темы | 8 | между строками и контролами |
| внутренний отступ карточки | 12 | `:pad` у карточек «Пул» |
| зазор группы | 16 | между блоками действий |

Других отступов нет: 6, 14, 18 — не токены, а случайность.

## Кегли

| Роль | Размер |
|---|---|
| основной текст, кнопки | 14 |
| мелкие подписи, статус | 12 |
| заголовок экрана | 20 |
| крупное число в карточке | 30 |

## Цвета

| Роль | Значение |
|---|---|
| фон окна | `Visuals::dark()` (egui) |
| акцент / выделение | `#388bfd` |
| текст на акценте | по яркости акцента: тёмный на светлом, белый на тёмном |
| основной текст | `#e8eef7` |
| второстепенный | `#8b949e` |
| статус | `#69b4ff` |
| опасность | `#e5484d` |
| успех | `#39d353` |

## Радиус и контраст

- Радиус: `8` для контролов и карточек, `2` для холста (там важна рамка, а не скругление).
- Основной текст — не ниже 4.5:1 к фону; второстепенный — не ниже 3:1.
- Текст на акценте выбирается вычислением яркости, а не «на глаз»: иначе выделенный инструмент
  превращается в пустую синюю плашку (так и было, пока не починили).

## Правила

1. Новый контрол берёт токены, а не свои числа.
2. Проверка целостности — часть состязательного прогона (`adversarial-ui-test`): случайный кегль, цвет вне
   палитры и отступ не из шкалы считаются дефектом.
3. Тема живёт в одной строке модели: смена направления — это правка `theme`, а не переписывание экранов.
